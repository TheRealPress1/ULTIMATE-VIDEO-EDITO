# UVE roadmap

Updated 2026-11-03. The remaining approved milestones are implemented locally. External service activation is tracked separately below.

## Editing workflows

| Improvement | Implemented behavior | Review notes |
| --- | --- | --- |
| Uninterrupted local editing | No permission prompts in Claude Code or Codex chats. Project edits, Cutroom tools, web search/fetch and sandboxed commands run automatically, and files outside the project are never replaced. Claude chats also refuse deleting or system shell commands, local network addresses and credential stores, with guidance the agent can act on; Claude chats' commands can download from public hosts; Codex chats run in Codex's workspace sandbox without network access (it can't hide credential stores) and get web and platform media through Cutroom's tools. Edited caption files refresh their live layers. | Agent questions about an ambiguous brief remain. Cutroom tools check their own output paths. Instagram publishing stays behind the in-app approval queue. Caption refresh preserves the mounted layer and undo history. |
| Web images and media | Keyless Openverse and Wikimedia Commons search for images, video and audio with license filters and thumbnails. Downloads of a result or a user's link (direct media, or the image/video a page declares) land in `assets/web/`, are imported into the library with provenance, and are credited in the project's `CREDITS.md`. A shared skill builds a timeline of visuals from a script and retimes it to a recorded voice. | Search results carry verified license terms; user links are marked unverified. Platform links (YouTube, Instagram, TikTok and similar) are routed to the platform media tools. Local and private network addresses are refused and sizes are capped per media kind. [Details](reference/tools/web-media.md). |
| Music, sound effects and platform media | Search YouTube, YouTube Music and SoundCloud, plus best-effort creator listings on other platforms, and download audio (default) or video from those sites into the project library with a credit, using an app-managed downloader whose releases are checksum-verified and must carry yt-dlp's signature. A curated music and sound-effect catalog with personal picks, and skills for choosing music (including official instrumentals), timing effects to events, and mixing them under speech. Scene finishing keeps listed sound effects unprocessed and outside the music ducking. | Platform rights are not verified and copyrighted songs may be muted when posted. Instagram and X keyword search, signed-in downloads, vocal separation and music identification are not included; vocals and beats are checked with the audio add-on below. [Details](reference/tools/media.md). |
| Audio intelligence | Local CLAP and AudioSet models ([earshot](https://github.com/Leonxlnx/earshot) 0.4.0, MIT) describe, match, rank and find sounds, check instrumentals for vocals, measure loudness, tempo and beats, and review a draft export's sync to its cuts and cues. A bank of 252 original, code-made sound effects renders into the project with onset and peak times for placement. The add-on installs itself on the first sound tool call, with no prompt; Settings shows its status, Install now and Remove. Music, sound-effect, final-review and audio-finishing skills use it, with two adapted earshot guides. | About 2.4 GB on disk plus caches kept under 500 MB; Apple silicon only, since PyTorch has no current Intel macOS build. Downloaded on first use at pinned versions and checksums, never bundled, and offline after the install. Verdicts are model evidence, not proof, and taste is not measured. [Details](reference/tools/sound.md). |
| Scripting and briefs | A scripting skill (with reference pages read through `skills`) takes an idea or a draft through audience, thesis, opener, beats and a shot plan, written to the project's `brief.md` in a documented, tolerant format. `script_lint` runs fixed checks (spoken length against the target, greeting or self-introduction openers, long sentences, missing specifics, weak closes); `script_read_compare` aligns a recorded read or multi-take shoot to the script line by line. | Lint flags are prompts, not editorial verdicts. The agent never invents the creator's facts; it asks. No script panel in the editor yet: `brief.md` is a plain project file. [Details](reference/tools/script.md). |
| Clean talking-head edits | A clean-edit skill picks the best attempt at each idea and removes retakes, fillers and dead air at a stated pace profile (tight by default for short vertical talking heads, natural for long interviews and podcasts; the brief and saved style override). Transcript editing suggests tight pauses with a measured or fixed threshold, custom fillers and retakes; `check` flags visible stretches too short to read. | Suggestions are candidates to review, not automatic cuts. The agent cannot hear the audio and says so; joins are checked with waveforms, captures and quality review. [Details](reference/tools/transcript-edit.md). |
| Agent memory and user skills | `memory` keeps two short, budgeted lists, the user's profile and their setup, safety-scanned on every write and before it reaches a chat, with history kept. In-app chats get it at session start; other MCP clients are told to read it first. `skill_write` saves procedures the user wants repeated as their own skills, validated whole and archived instead of deleted, listed by `skills` with category `user`. Settings shows both, with a pause. | Saved only when the user asks; nothing inferred from footage, transcripts or web pages. Credentials, contact details and agent-aimed instructions are refused. `CUTROOM_MEMORY=0` turns both off. [Details](reference/tools/memory.md). |
| Whole-video analysis and masks | `analyze` builds one timestamped evidence pack per file: speech, frames picked at visual changes within a budget, visual-index labels and on-screen text, silences, and sound events once the audio add-on is ready (it starts the add-on install in the background otherwise). Long files run as a resumable, cached job. `segment` previews and tracks a SAM 2.1 mask from a box or points. `transcribe` takes a window, a language and an optional larger model. | Sampled evidence, not watching: brief events between frames are missed and actions, identities and music are not recognized. The larger transcription model downloads only when a call asks for it. [Details](reference/tools/analyze.md). |
| Reference video editing | Local cut/caption/frame/palette measurements, editable layout copy, and agent handoff for a reference-guided edit. | Original scene preserved; measured evidence is distinguished from unknown fonts/motion. [Details](reference/tools/reference-style.md). |
| Long footage playback | Automatic local 720p preview copies, bounded cache, source verification, original-quality export and audio. | HDR and unsupported footage fall back to originals. [Details](playback-performance.md). |
| Automatic social formats | Editable vertical, square and landscape variants, local audio/video speaker framing with smoothed tracks and longer context, steadier camera decisions, scene-time framing corrections, face following and caption insets. | Original scene preserved; uncertain speaker evidence holds briefly or fits the full image. No real identities or off-camera diarization. [Details](reference/tools/reframe.md). |
| Long recording analysis | Two-hour speech indexing, captions, face/speaker analysis, native visual indexing and rendered quality review, using bounded sections and persistent progress. | Completed sections resume for unchanged sources/settings; optional CLIP embeddings remain checkpointed per completed video. Audio finishing retains its separate limit. |
| Project version history | Named and automatic checkpoints, previews, file/layer comparisons, whole-project and selective restoration. | Restore creates a recovery checkpoint and checks for conflicts. Maximum 50 versions within 100 MB. [Details](project-safety.md). |
| Visual footage search | Persistent local image labels, visible text and person counts, with timestamped previews and B-roll audition ranges. Optional local CLIP image/text matching ranks descriptions after explicit model download. | Sampled frames can miss short shots; descriptions return candidates, not proof of an action. No media/query upload. [Details](reference/tools/visual.md). |
| Transcript timeline editing | Remove words or reorder passages in the current scene; preview conservative filler/quiet-pause suggestions; cut supported video/audio/graphics and rebuild captions together. | Saves a named recovery version and one Undo step. Unsupported timing containers fail before editing. [Details](reference/tools/transcript-edit.md). |
| Audio finishing | Integrated LUFS, true peak and loudness range; dialogue leveling, optional steady-noise reduction, two-pass normalization and editable music ducking. | Creates a separate scene and WAV derivative. Final combined mix is measured separately; listen before export. [Details](reference/tools/audio-finish.md). |
| Rendered quality review | Clickable observations from actual sampled frames, caption/text layout and the scene audio mix: dark frames, borders, potential overflow, clipping, long pauses and audio joins. | Does not measure lip-sync, speaker identity, narrative quality or HDR mastering. Sampling can miss brief problems. [Details](reference/tools/quality-review.md). |
| Instagram workflows | Browser authorization client and deployable broker, durable Reel draft/approval queue, scheduled attempts while the app is open, and cached post comparisons. | Agents cannot approve or publish. Changing accounts pauses approvals. Browser login and live publishing require deployment and account acceptance below. [Details](instagram-publishing.md). |
| Export and distribution | Native AAC finalization with encoder-reported priming/edit lists, atomic file replacement, signed release workflow, manual update UI and deployable feed. | Native timing regressions are tested. SDR metadata is retained by video stream copy; exact color/HDR fidelity is not claimed. Releases are public: signed/notarized app and DMG artifacts on the GitHub releases page, verified before upload and downloaded without an account. Automatic in-app updating (a public feed is now possible) and a separate clean-Mac acceptance remain. [Details](releasing.md). |

## External activation still required

- Deploy the Instagram authorization broker to an HTTPS domain, supply the Meta app secret on that server, and configure the callback/permissions in Meta. Then test browser authorization with the authorized creator account.
- Provide public HTTPS hosting for Reel media. The queue does not upload local exports to a media host. Perform a deliberate live publish only after reviewing the exact media, caption and destination.
- Publish installers on the public GitHub releases page. For automatic in-app updates, host a signed update feed (the static manifest can sit beside the public assets) and build it in; never embed a GitHub token or other credential. Complete clean-Mac acceptance on a separate machine. See [release setup](releasing.md).
- Compare final exports in target players/platforms before promising exact color fidelity or support for HDR mastering.

## Planned next

- A post-library skill and tools that retrieve, inspect and reuse the creator's past Instagram posts (their own media, filters, pagination and relative performance).
- An optional user-supplied Gemini key for semantic audio and video questions, and truthful model, voice and account tools.
- A Claude Code plugin manifest so the skills load natively outside Cutroom, search over past in-app chats, and opt-in learning from idle chats.
- A script panel in the editor that shows `brief.md` and links script lines to their takes.

## Acceptance expectations

- Work on isolated project copies; preserve the user's original scene, captions and media.
- Keep caption timing and source audio aligned through trimming, rearrangement, reframing and audio processing.
- Reject stale transcript/search/review results when source media or the composition changes.
- Save recovery checkpoints before destructive timeline edits and restoration.
- Report uncertainty in sampled visual evidence and automated review findings.
- Treat Instagram draft creation, user approval and actual publication as distinct states; never retry an ambiguous publish automatically.
- Verify standalone binaries and local model assets work without a development server or Homebrew runtime.
